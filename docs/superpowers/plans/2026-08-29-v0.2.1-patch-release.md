# AgentShare v0.2.1 Patch Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an immutable AgentShare v0.2.1 patch release that delivers the Codex minimum-version-plus-capability compatibility fix and updates the public handoff bootstrap to install that release.

**Architecture:** Keep `v0.2.0` immutable. Build `v0.2.1` from a verified release-candidate commit, stage one prerelease tarball, point only the trusted handoff Worker at that immutable asset, verify the public bootstrap and disposable v1/v2 lifecycles, then promote the same asset to stable. The ciphertext relay protocol and Durable Object schema do not change.

**Tech Stack:** TypeScript, Node.js 22/24, npm workspaces, Vitest, GitHub Actions, GitHub Releases, Cloudflare Workers/Wrangler.

**Spec:** `docs/recipient-compatibility.md` and `docs/operations/cloudflare-deployment.md`

## Global Constraints

- Do not replace or mutate the existing `v0.2.0` release asset.
- Package version for this release is exactly `0.2.1`.
- Public bootstrap must pin exactly `v0.2.1/agentshare-0.2.1.tgz` before production handoff deployment.
- Codex compatibility remains `>= 0.145.0` plus required runtime capability checks; launcher sandbox arguments are unchanged.
- Claude Code remains an exact-reviewed adapter, but an unchanged Claude adapter is not a blocker for this Codex-only patch release.
- Preserve relay/handoff split origins and all published Durable Object migration tags.
- Temporary staging/deployment workflows must not land on `master`.
