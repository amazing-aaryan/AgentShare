## Recorded technical validation

The candidate passed 383 tests plus eight opt-in skips and coverage thresholds,
126 release-tool tests, build/lint/format, ACB conformance, isolated package
installation, edge runtime, both Worker dry runs and a dependency audit with
zero advisories at the time. The six-job CI matrix covered Ubuntu, macOS and
Windows with Node.js 22 and 24. Real hostile-isolation and grounded-continuity
checks passed. These recorded results describe this release's verification; they
are not a current dependency audit or live-host test of every platform.

The exact public archive passed all nine public Codex diagnostic stages. Real
Windows terminal/native journeys covered:

- reviewed context selection and publication;
- authenticated MCP file/conversation reads recovering independent canaries and
  task context;
- proposal delivery while the owner's files remained unchanged;
- separate reviewed owner approval;
- refresh of the original recipient attachment to the approved revision;
- authenticated revocation returning HTTP 410, zero owned shares, stopped
  fixture processes and completed scoped temporary-path cleanup.

First-use checks also covered native Install/Keep, partial-form Cancel with no
installation, Install/On Request with a private backup and preservation of
unrelated settings, and an actual later observation of unchanged active-session
permissions. Fresh crowded-session managed-skill discovery/read was observed.

Two quiet recipient windows, measured while the creator was stopped, retained
matching canonical model-cache hashes. A separate grounded read passed with the
existing Codex 0.160.0 installation. That additional observation is not the
entire 0.155.1 acceptance journey rerun at 0.160.0.

## Release decision and evidence limits

Native choices and release review were performed by agents under the owner's
explicit delegation. Independent final review checked all 81 then-retained
attachment hashes and absence of all 13 named fixture/runtime paths before
approving metadata-only promotion. Redacted evidence was retained in the owner's
local release workspace; raw private state and provider credentials are not
published in this record.

This decision does **not** establish the frozen personal-human 18-stage
certificate in the [v6 acceptance contract](../release-v0.3.16.md). Historical
profiles and verifier semantics remain unchanged, including `promotable: false`.
Earlier failed/cancelled attempts, transient fetch failures and active-host
metadata drift remain in the retained evidence. The writer of that drift was not
observed. The final quiet measurements supplement those records; they do not
erase them.

The final helper also retained an obsolete-model rejection before publication
and an assertion failure when a successful proposal omitted its ID from model
stdout. Independent authenticated inbox evidence confirmed the sole expected
proposal without duplicate submission.

Claude execution was excluded at the owner's request. macOS/Linux passed CI but
did not receive the same live end-to-end test. Automatic managed-skill injection
into a crowded session was not established. The native Windows restricted-tool
profile is not an OS-enforced filesystem read-deny boundary. These limits remain
part of the release decision; stable status does not remove the public-beta data
warning or normal creator review requirements.
