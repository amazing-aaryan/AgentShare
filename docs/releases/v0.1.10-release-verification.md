# AgentShare v0.1.10 Release Verification

Date: 2026-08-19  
Release candidate branch: `fix/handoff-trust-and-lifecycle`  
Status: **RELEASED AND DEPLOYED**

## Blocking condition

The independent production handoff origin is not serving the v0.1.10 handoff
Worker yet. A live split-origin diagnostic on 2026-08-19 created and uploaded a
real disposable share through the production relay, then fetched its generated
handoff URL at:

`https://agentshare-handoff.carnation-vermicelli.workers.dev`

The handoff request returned HTTP 404. The release must not be published while
that hostname is unavailable because the v0.1.10 creator CLI generates links on
that origin by default.

The same live diagnostic confirmed that the production relay accepted the new
cross-origin metadata flow: create/upload/replay/expiry behavior and browser
metadata CORS passed against
`https://agentshare-relay.carnation-vermicelli.workers.dev`.

## Deployment order

For v0.1.10, deploy and verify the independent handoff Worker before publishing
the creator package. Publishing the package first could allow clients to create
links whose browser endpoint is not live. Existing v0.1.9 links remain
independent of the new handoff Worker and are the rollback baseline.

See `docs/operations/cloudflare-deployment.md` for the deployment and rollback
procedure.
