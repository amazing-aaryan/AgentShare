## Scope

v0.1.11 is a patch release for CLI-managed updates plus the security hardening
merged to `master` after v0.1.10. The relay edge entrypoint and secret scanner
change, while the protocol encryption design and production Durable Object
sequence are preserved, including the active `QueryObject` v3 migration. Active
install and recipient commands, both production Workers, package metadata,
tests, and operations documentation advance to v0.1.11. Historical v0.1.10
evidence remains preserved.

## Security, privacy, and beta position

- Public-beta warning remains required.
- Do not claim production-grade guarantees.
- Do not send production credentials, regulated data, or other high-risk data.
- Secret scanning remains best-effort.
- Bearer-link forwarding, trusted handoff-origin compromise, endpoint
  compromise, and model-provider exposure of selected excerpts remain explicit
  residual risks.
- Citations establish bundle provenance, not external truth.
- The updater trusts GitHub release metadata and assets. In-client checksum or
  signature verification remains post-beta hardening, while every release must
  publish and independently verify a SHA-256 digest.
